Mega - Contact Lock Identification

Controla el diligenciamiento del formulario de contactos en Odoo y guía al usuario en el orden correcto de captura.

Descripción general

Este módulo fue desarrollado para mejorar el proceso de creación y edición de contactos en Odoo, evitando errores de digitación y registros incompletos.

La solución aplica restricciones visuales y funcionales sobre el formulario de contactos, obligando a seguir un flujo lógico de diligenciamiento antes de habilitar el resto de la información.

Objetivo del desarrollo

Reducir errores en la creación de terceros y asegurar que la información se registre en el orden correcto.

  • Primero se registra el número de identificación.
  • Después se habilita el país.
  • Luego se habilita el estado.
  • Después se diligencia la ciudad.
  • Finalmente se habilitan los demás campos del contacto.

Funcionalidades implementadas

  • Se agregaron alertas visuales en la parte superior del formulario para guiar al usuario paso a paso.
  • Se bloqueó el nombre del contacto mientras no exista identificación.
  • Se ocultó el bloque de dirección mientras no exista número de identificación.
  • Se controló la secuencia de diligenciamiento entre país, estado y ciudad.
  • Se ajustó la visibilidad de campos relacionados con empresa.
  • Se creó un grupo de seguridad para controlar quién puede visualizar ciertos campos del formulario.

Paso 1. Ingreso de identificación

El formulario exige primero registrar el tipo y número de identificación del contacto. Mientras este dato no exista, el resto de campos queda restringido.

Paso 2. Selección de país

Una vez diligenciado el NIT o la cédula, el sistema habilita el campo país para continuar con el flujo.

Paso 3. Selección de estado

Después del país, el formulario habilita el estado o departamento correspondiente.

Paso 4. Ciudad y habilitación del resto del formulario

Una vez diligenciada la ciudad, el sistema habilita el resto de campos del contacto, como dirección, teléfono, correo electrónico, sitio web, etiquetas y demás información complementaria.

Grupo de seguridad implementado

El módulo incluye un grupo de seguridad para controlar la visibilidad de ciertos campos relacionados con empresa.

  • Nombre del grupo: Company, Module Contact
  • XML ID: group_contact_company_menu_lock

Esto permite que ciertos campos solo aparezcan para usuarios autorizados.

Resultado final

  • Menor probabilidad de errores en la creación de contactos.
  • Mayor control sobre la información básica del tercero.
  • Mejor experiencia para el usuario mediante alertas visuales.
  • Formulario más guiado, ordenado y seguro.

Resumen técnico

  • Herencia de vista sobre base.view_partner_form.
  • Uso de alertas visuales antes del <sheet>.
  • Uso de atributos readonly, invisible y groups.
  • Control de visibilidad y edición sobre campos del formulario principal de res.partner.
  • Creación de grupo de seguridad para campos relacionados con empresa.
